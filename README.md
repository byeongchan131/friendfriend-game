# 프렌드프렌드 (온라인 버전)

친구들과 링크 하나로 즐기는 "왕 마음 맞히기" 계단 게임입니다. 최대 8명, 로그인 없이 닉네임·색만 고르면 참가할 수 있어요.

## 게임 방법
1. 방장이 방을 만들고 초대 링크(또는 4자리 코드)를 공유합니다. 모두 준비하면 방장이 시작해요.
2. 무작위로 왕이 정해지고, 나머지는 계단 맨 아래에서 시작합니다.
3. 참가자는 왕에 대한 질문을 고르거나(100개 이상, 🎲 랜덤) 직접 써서 보냅니다.
4. 왕이 답하면 같은 질문이 질문자에게 돌아와요. 질문자가 답하면 왕이 평가합니다.
5. 매우 싫음 -1칸 · 싫음 유지 · 좋음 +1칸 · 매우 좋음 +2칸 (최종칸 바로 아래에서는 +1칸까지).
6. 최종칸에서 좋음 이상을 받으면 승리! 다음 판의 왕이 됩니다.

## 링크로 바로 플레이하기 (최초 1회 설정, 약 10분)
1. [Firebase Console](https://console.firebase.google.com)에서 프로젝트를 만들고 웹 앱을 추가한 뒤 SDK 설정값을 `firebase-config.js`에 붙여넣습니다.
2. Authentication > Sign-in method에서 **익명(Anonymous)** 을 사용 설정합니다.
3. Realtime Database를 만들고 Rules 탭에 `database.rules.json` 내용을 붙여넣어 게시합니다.
4. 터미널에서 배포합니다.
   ```
   npm i -g firebase-tools
   firebase login
   firebase use --add        # 만든 프로젝트 선택
   firebase deploy --only hosting,database
   ```
5. 배포 후 나오는 주소(https://프로젝트ID.web.app)가 게임 링크입니다. 방 안에서 "초대 링크 복사"를 눌러 친구에게 보내세요.

## 참고
- 방은 임시 방입니다. 모두 나가면 자동으로 삭제돼요. 방장이 나가면 다음 사람이 방장이 되고, 연결이 25초 이상 끊긴 사람은 자동으로 방에서 빠집니다.
- 권한 검증은 클라이언트 로직과 DB 규칙 기반이라, 불특정 다수에게 장기간 공개한다면 Cloud Functions 같은 서버 검증을 추가하세요.
